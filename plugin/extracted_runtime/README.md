# MH Frame 在线运行时 0.5.14

本版修复冻结请求/消息数组导致的只读属性报错。使用独立请求副本在适配器发送边界应用提示词与思考等级，不修改 Harness 的原请求、会话记录或用户思考等级配置。

## 使用

只有在线服务确认开发者身份后才显示自定义输入框。输入多行提示词，开启“自定义提示词”开关会在同一次保存中启用当前输入内容。已开启后继续编辑，需要点击“保存提示词”。关闭自定义开关会保留文字并恢复所选在线模式。点击某个在线模式的“启用”也会关闭自定义模式。破甲总开关仍控制插件提示词是否启用。修改从下一次请求起生效。

授权有效、总开关开启时：

```text
自定义开关开启：自定义内容 + 自定义内容
自定义开关关闭：所选在线内容 + 所选在线内容

```

自定义模式完全排除在线内容，后台在线刷新不会改变这个选择。空白内容不能启用；即使旧配置中存在已启用但为空的自定义内容，也不会回退到在线提示词。授权失效或现有保护机制触发后，继续停止全部插件提示词注入。

插件提示词不注册到会话可见的系统提示词槽位，而是在模型适配器发送前加入新请求，并替换发送副本中的 Harness 原生系统提示词。原生会话显示的 Harness 内置系统提示词仍可能出现，那不是插件选中的提示词。旧版已经写入的历史内容不会被删除。自定义文字仍会保存在插件设置中；此功能不承诺隐藏本地配置、提供商请求调试日志或模型回答中的复述。

Flash 模型名只要包含 `Flash`（不区分大小写），当前会话上下文占用低于阈值时临时使用 `off`；达到阈值后使用用户原思考等级。此功能始终启用，不显示独立开关。阈值滑块标签为“阈值设置”，范围 5%–50%，步长 5%，默认 30%，附重置按钮和“稳定性，非必请勿调整”。

占用读取 Harness 的 `contextPressure` 会话投影，优先使用 `projectedTokens`，与界面使用相同的四舍五入规则；压缩后会随最新占用重新判断。在首次用量样本或上下文容量尚不可用时使用 `off`。生成会话标题和上下文压缩等辅助调用保持原请求。

## 修改位置

- `lib/index.js`：互斥选择、请求态隐藏注入、Flash 思考转换和阈值验证。
- `lib/provider-request.js`：适配器发送边界兼容层、卸载还原、真实上下文占用读取。
- `lib/settings.js`：客户端设置传输 schema 同步控制字段。
- `lib/client.js`：开发者自定义编辑与阈值滑块。
- `customSystemPrompt` 默认为空文本，`customSystemPromptEnabled` 默认为 `false`。

## 本地验证

```powershell
npm.cmd run test:prompts
npm.cmd run test:prompt-ui
```

前者使用本机解析到的 Harness LLM 运行时，验证冻结请求经过真实 prepared-call 检查和分发后得到正确发送副本，同时验证旧适配器兼容、动态注册、卸载还原、授权及保护行为。

界面测试使用实际 `client.js`、实际插件设置 API handler、真实 Harness 系统提示词组装器，并以合成授权与临时设置存储运行。不会连接在线授权服务或修改用户 profile。输出位于 `Harness/dist/custom-exclusive-verification/`。

界面测试需要 esbuild、Playwright 和 Chrome。本机默认复用桌面 `Chat` 项目中的测试依赖；其他环境可将 `MHF_TEST_TOOLS_MANIFEST` 指向含这些依赖的 `package.json`，并用 `MHF_TEST_BROWSER_CHANNEL` 指定浏览器 channel。

## 验证范围

测试断言适配器收到互斥的双份提示词，同时上游请求仍为未修改的原对象；覆盖阈值边界、会话投影和 UI 显隐。使用本地记录适配器，没有执行在线模型调用。适配器兼容层依赖 Harness 当前的注册表及 `llm/adapters-updated` 事件；未来 Harness 改变接口时可能需要更新插件。
